# UI Reference Images

Drop screenshots here for Claude Code to look at, then just say
"check ui_reference" (no need to type the full path).

Suggested naming so it's obvious what each one is:

- `current_<screen>.png` — how it looks now in-game (the problem)
- `wanted_<screen>.png` — a reference of how you want it to look
  (a screenshot from another game, a sketch, an edited mockup — anything)

Example: `current_hud.png`, `wanted_hud.png`.

Not used by the game at runtime — reference only.
